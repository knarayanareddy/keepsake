Slide 03 · Architecture

How It Works: Under the Hood

Two minimal smart contracts, write-once attester binding, and ownerless immutable record keeping.

// contracts/World.sol — Guarded Mercy Attestation function spare(address other) external { Player storage p = players[msg.sender]; Player storage o = players[other]; if (p.ammo == 0) revert NoAmmo(); // Must have kill shot (HP <= 2 and opponent armed) if (o.hp > SPARE_WINDOW || o.ammo == 0) { revert NotKillShot(); } // World is the ONLY authorized caller to HonorLog bytes32 uid = log.attest(msg.sender, other, SPARE); }

1. World.sol (Attester)

Handles game mechanics, grid movement, and strict precondition checks. Only valid strategic choices trigger attestation minting.

2. HonorLog.sol (Registry)

Write-once attester pin (setWorld). Mints non-transferable soulbound records. Fully ownerless via renounceOwner().

3. Universal Verification

Any external smart contract or dApp can query HonorLog.verify(uid) to verify provenance, attester identity, and historical claims.
